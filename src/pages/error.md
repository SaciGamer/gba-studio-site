# Error

Oh no, you encounted an error in GBA Studio...

At this point before doing anything you should make a back up of you project folder just in case anything happens.

Once you've made a backup you may still be able to save your project using `File / Save` in the menu. If this fails revert back to the backup.

## Reporting Issues

If you've come across an error in GBA Studio it would be greatly appreciated if you file an issue at:
https://github.com/SaciGamer/gba-studio/issues

## Getting Help

The best place to get help when GBA Studio isn't working is either the [Discord channel](https://discord.gg/fa8TZvc9sC).

# Primer proyecto

1. Crea un proyecto nuevo y guárdalo en una carpeta escribible.
2. Abre Game World y crea o selecciona la escena inicial.
3. Añade un fondo a una layer.
4. En Sprites Editor, selecciona un sprite y añade un actor a la escena.
5. Selecciona el actor, abre el editor de eventos y añade una interacción.
6. Conecta el flujo desde el nodo de entrada y guarda.
7. Ejecuta **Play** y comprueba la ROM en el emulador.

El repositorio también contiene `sample_project_example/sample_project.gbaproj`, con escenas, sprites, paletas, diálogos y triggers para comparar este flujo.

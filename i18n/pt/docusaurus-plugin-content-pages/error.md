# Erro

Ops, você encontrou um erro no GBA Studio...

Neste momento, antes de fazer qualquer coisa, faça um backup da pasta do seu projeto, caso algo aconteça.

Depois de fazer o backup, você ainda poderá salvar seu projeto usando `Arquivo / Salvar` no menu. Se isso falhar, restaure o backup.

## Reportando Problemas

Se você encontrou um erro no GBA Studio, agradecemos se você registrar um problema em:
https://github.com/SaciGamer/gba-studio/issues

## Obtendo Ajuda

O melhor lugar para obter ajuda quando o GBA Studio não estiver funcionando é o [canal do Discord](https://discord.gg/fa8TZvc9sC).

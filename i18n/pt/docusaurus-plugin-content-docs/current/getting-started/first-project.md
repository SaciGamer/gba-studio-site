# Primeiro projeto

1. Crie um projeto novo e salve-o em uma pasta gravável.
2. Abra o Game World e crie ou selecione a cena inicial.
3. Adicione um background a uma layer.
4. No Sprites Editor, selecione um sprite e adicione um ator à cena.
5. Selecione o ator, abra o editor de eventos e adicione uma interação.
6. Conecte o fluxo a partir do nó de entrada e salve.
7. Execute **Play** e confira a ROM no emulador.

O repositório também contém `sample_project_example/sample_project.gbaproj`, com cenas, sprites, paletas, diálogos e triggers para comparar com este fluxo.

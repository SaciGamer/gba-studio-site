# Real hardware

Hardware testing depends on the flashcart or transfer device being used. Build the ROM, copy it using that device's documented workflow and test the same scenarios exercised in mGBA.

The site does not replace the manual for a specific flashcart. Keep the original project and build configuration with the ROM so a hardware-specific issue can be reproduced without modifying generated files.
